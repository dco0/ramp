# RAMP
Some code for RAMP 2026. Website at [https://dco0.github.io/ramp/](https://dco0.github.io/ramp/), code at [https://github.com/dco0/ramp](https://github.com/dco0/ramp).

## [Tilings](https://dco0.github.io/ramp/tiling.html)
Render various hyperbolic tilings.

Sources:
 - `dist/tiling.html`, the website
 - `src/hyper.ts`, for hyperbolic geometry
 - `src/weyl.ts`, for navigating the plane with group theory
 - `src/tiling.ts`, the main code generating the tiling
 - `src/tile_style.ts`, used for drawing the different types of tilings
